# Learning Systems Atlas

**Signal. Structure. Strategy.**

A reproducible, production-grade atlas of supervised, unsupervised, deep, and
reinforcement learning systems—from mathematical baselines to deployed
experiments.

The active engineering roadmap is developed on `dev` and promoted through
`main` and `prod` after validation.

## Status

Repository foundation in progress. The first sprint establishes the shared
experiment contract and reference baselines for supervised, unsupervised, and
reinforcement learning.
