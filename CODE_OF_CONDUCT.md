# Code of conduct

Participation in this project requires respectful, technically honest, and
constructive collaboration.

## Expected behavior

- Critique ideas, code, methods, and evidence—not people.
- State assumptions, uncertainty, limitations, and conflicts of interest.
- Respect privacy, licenses, attribution, and data-use restrictions.
- Welcome questions and different levels of domain experience.
- Report potential data leakage, unsafe claims, or security issues responsibly.

Harassment, discrimination, threats, deliberate misrepresentation of results,
or publication of private/proprietary information is not acceptable.

The repository owner may edit or remove contributions and restrict participation
when needed to uphold these standards. Sensitive security concerns should use
the private process in [SECURITY.md](SECURITY.md); other conduct concerns can be
raised privately with the repository owner through GitHub.
